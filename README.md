Simple project to test using Claude code, VSCode, Git, and related entities.

Here I will ask Claude to generate a Java program that helps remove the live photo .mov files imported from iPhones.  The criteria is that if there exists a file x.heic and there also exists a file x.mov then the x.mov file is a live photo video and can be removed.  We also want the extension testing to be case insensitive.
